# Geo Realt — обзор проекта

Последнее обновление: 23 октября 2026 года.

## 1. Назначение

Geo Realt помогает агентствам и риэлтерам быстрее находить свежие объявления о недвижимости в Грузии. Система объединяет публичные предложения с нескольких площадок, позволяет настраивать поиски, вести ленту совпадений и отправлять уведомления.

- Рабочий интерфейс: [georealt.github.io](https://georealt.github.io/)
- Telegram: [@georealt_bot](https://t.me/georealt_bot), доступ по приглашениям
- Публичный репозиторий веб-приложения: [georealt/georealt.github.io](https://github.com/georealt/georealt.github.io)
- Закрытый репозиторий API и парсеров: [georealt/backend](https://github.com/georealt/backend)
- Предыдущий репозиторий/сборка: [zettts/geo-realt-myhome](https://github.com/zettts/geo-realt-myhome)

Сейчас продукт развивается как веб-приложение, которое можно установить на домашний экран телефона. Упаковка в отдельные приложения Android и iOS — возможный следующий этап.

## 2. Для кого и основной сценарий

Продукт рассчитан на профессиональных риэлтеров и агентства, которым важно оперативно замечать новые предложения. Доступ выдают вручную по логину и паролю; публичной регистрации и встроенной оплаты нет. На экране входа временно оставлен демонстрационный режим **Guest**.

1. Пользователь задаёт один или несколько сохранённых поисков.
2. Сервер проверяет новые объявления по расписанию и сопоставляет их с активными поисками.
3. Совпадения появляются в общей ленте с указанием поиска, которому они соответствуют.
4. Риэлтер отмечает результат работы, звонит по доступному номеру, сохраняет понравившиеся объявления и добавляет личные заметки.

Администратор может создавать пользователей и менеджеров, задавать менеджеру лимит агентов, период действия и паузу. Менеджер создаёт и удаляет агентов в пределах лимита. Даты доступа агента наследуются от менеджера; пустые даты менеджера означают бессрочный доступ.

## 3. Возможности интерфейса

Веб-приложение имеет интерфейс на английском, русском и грузинском языках. Перевод интерфейса не зависит от языка объявления. Заголовки и описания берутся на доступном языковом варианте площадки; автоматический перевод объявлений внешним AI-провайдером пока не подключён.

Основные разделы:

- **Объявления** — общая лента с фильтрами и сортировкой по дате источника.
- **Новые совпадения** — события, привязанные к сохранённым поискам. Совпавшее объявление показывается один раз, даже если подходит нескольким поискам; можно отфильтровать ленту по поиску и статусу. Удаление поиска удаляет его связи с событиями, событие сохраняется, если связано с другим поиском.
- **Избранное** — личный список объектов с заметками пользователя.
- **Сохранённые поиски** — параметры мониторинга; поиск можно приостановить, возобновить, изменить или удалить.

Карточки поддерживают галерею фотографий со стрелками и свайпом; порядок изображений соответствует источнику. Сердечко добавляет объект в избранное. Если номер доступен в публичных данных объявления, показывается кнопка звонка; иначе открывается оригинальная страница площадки. Вся карточка ведёт на объявление, за исключением собственных кнопок галереи, избранного и звонка.

Фильтры включают источники, тип сделки (аренда/покупка), тип недвижимости (квартира, дом, коммерческая), тип рекламодателя (владелец/агент), город и зависящие от города районы, цену, площадь, число комнат и спален. Для квартир предусмотрен диапазон этажей. Для коммерческих помещений доступны назначения: офис, торговое помещение, склад, промышленное, общепит, гостиница и другое. Поиску можно задать несколько источников и районов.

Для цен в базе сохраняются доступные суммы USD и GEL. API использует официальный курс Национального банка Грузии для пересчёта отсутствующей суммы; временный сбой может использовать кэшированное значение с пометкой устаревшего курса. Перевод валюты не меняет исходную цену объявления.

## 4. Подключённые площадки

Обход ограничен объявлениями и каталогами недвижимости **в Грузии**.

| Источник | Текущий сбор |
|---|---|
| [MyHome.ge](https://www.myhome.ge/) | Квартиры, дома и коммерция; аренда и покупка; доступные языковые версии и даты источника |
| [ss.ge](https://home.ss.ge/) | Квартиры, дома и коммерция; аренда и покупка; публичные контакты и дополнительные страницы объявлений |
| [Korter.ge](https://korter.ge/) | Квартиры, дома и коммерция; аренда и покупка; детали, контакты и галереи |
| [Realting.com](https://realting.com/ru/georgia) | Разделы жилья и коммерции только по Грузии; доступные языки и дата обновления |

Каждая площадка имеет отдельный адаптер, который приводит объявление к общей модели: источник и ID, URL, тип сделки и недвижимости, параметры объекта, цены, город/район, тексты, телефоны и упорядоченный список изображений. Источники могут менять сайт и ограничивать автоматические запросы; покрытие не гарантирует обнаружение каждого опубликованного объекта.

Обход MyHome.ge и ss.ge ограничен несколькими страницами каждой категории; для ss.ge, Korter.ge и Realting.com ограничено число запросов к подробным страницам за один проход. Все четыре сборщика запускаются примерно раз в пять минут. Фактическая задержка включает время обхода и ответ сайта, поэтому это интервал проверки, а не гарантия доставки за пять минут.

Парсеры используют только публично доступные данные и не обходят CAPTCHA или закрытые способы раскрытия телефонов. Номера могут отсутствовать. Условия использования и права на данные/изображения каждого сайта нужно учитывать перед коммерческим масштабированием.

## 5. Новизна и уведомления

Исходная загрузка существующих объявлений не создаёт уведомления. Новым считается ID, впервые обнаруженный после начала соответствующего сохранённого поиска и прошедший проверку доступной даты публикации/обновления. Старое объявление, которое просто снова встретилось сборщику, не должно становиться новым событием.

### Веб push

Пользователь включает разрешение на уведомления сам. Новые совпадения доступны и в ленте без push. Отправитель группирует события в дайджест и учитывает успешные доставки для каждого устройства. На iPhone сайт нужно открыть как установленное веб-приложение с домашнего экрана и разрешить уведомления.

### Telegram

Бот [@georealt_bot](https://t.me/georealt_bot) принимает команды только в личном чате. Администратор создаёт одноразовую ссылку `/invite`; приглашение действует ограниченный срок. Бот отправляет только свежие новые объявления, найденные после подключения подписчика, с фотографией, кратким текстом и ссылкой на оригинал. Поддерживаются `/stop`, `/id` и выбор языка карточек `/language en`, `/language ru`, `/language ka`. Для новых подписчиков уже найденные до их подключения объявления повторно не рассылаются.

## 6. Техническая архитектура

```text
MyHome.ge ─┐
ss.ge ─────┤   4 сборщика по systemd timers
Korter.ge ─┤───────────┐
Realting ──┘            v
                    SQLite на сервере
                  /       |        \
                 v        v         v
             FastAPI   Web Push   Telegram bot
                 |
          HTTPS API через Nginx
                 |
       PWA на GitHub Pages
```

- Веб-приложение — статические HTML/CSS/JavaScript файлы, service worker и manifest; публикация через GitHub Pages.
- API и сборщики — Python/FastAPI, исполняются отдельными службами systemd.
- Рабочая СУБД текущего продукта — SQLite на сервере. **Oracle Cloud — провайдер виртуального сервера; Oracle Database для проекта не используется.**
- Главная база продукта: `/var/lib/geo-realt-realtor/realtor.sqlite3` на сервере.
- Внешний API: `https://georgiahomes.duckdns.org:8443/realtor`; health: `https://georgiahomes.duckdns.org:8443/realtor/health`.
- API-приложение внутри сервера слушает `127.0.0.1:8092`; Nginx принимает HTTPS на 8443 и проксирует `/realtor/`.
- Фотографии в БД не копируются: сохраняются URL и исходный порядок, сами изображения браузер запрашивает у площадок.
- Пароли пользователей хранятся как scrypt-хеши; API-сессии — JWT. Пользовательские поиски, feed, активности, подписки push, избранное и заметки разделены по аккаунтам.

Старый API для первоначального мобильного прототипа — отдельная система и отдельная база; он не обслуживает текущую веб-версию.

## 7. Основные маршруты API

Все пути ниже находятся под префиксом `/realtor` на публичном сервере.

| Методы и маршрут | Назначение |
|---|---|
| `GET /health` | Состояние API и последнего обхода |
| `GET /listings`, `GET /listings/{id}` | Поиск и просмотр объявлений |
| `GET /locations/cities`, `GET /locations/districts` | Локализованные города и районы |
| `GET /exchange-rates` | Курс USD/GEL и состояние кэша |
| `POST /auth/login`, `POST /auth/managed-login` | Вход по логину и паролю |
| `GET /me`, `PATCH /me/language` | Профиль и язык |
| `GET/POST/PATCH/DELETE /searches` | Сохранённые поиски |
| `GET /feed`, `PATCH /listings/{id}/activity` | Совпадения и статус обработки |
| `GET /favorites`, `GET /favorites/ids` | Список избранного и ID для сердечек |
| `PUT/PATCH/DELETE /favorites/{listing_id}` | Добавление в избранное, заметка и удаление |
| `GET /push/public-key`, `POST /push/subscribe`, `POST /push/unsubscribe`, `POST /push/test` | Web Push |
| `/admin/users`, `/admin/managers`, `/manager/agents` | Аккаунты, менеджеры и агенты; защищённые маршруты |

Интерактивные Swagger/ReDoc страницы отключены. JSON-схема доступна через `GET /openapi.json`.

## 8. Хранение и известные ограничения

- Перевод текста объявлений нейросетью/Translator API ещё не включён; интерфейс переводится отдельно.
- Сбор объявлений зависит от публичной структуры сайтов и квотирования запросов. Изменение площадкой HTML/JSON может временно остановить отдельный источник, не останавливая остальные службы.
- В базе сохраняются оригинальные URL изображений; источник может удалить/переместить фото или запретить внешнюю загрузку.
- Телефоны извлекаются лишь тогда, когда они доступны в публичном тексте или данных объявления; скрытые номера/CAPTCHA не обходятся.
- Автоматическое удаление старых объявлений и срок хранения базы пока не настроены. При эксплуатации следует контролировать размер SQLite и согласовать политику очистки.
- Для восстановления нужны целостная копия SQLite, состояние обходов и тот же приватный VAPID-ключ, иначе браузерные push-подписки могут перестать работать.
- Публичность GitHub Pages и API-маршрутов не делает пользовательские записи публичными; персональные функции требуют входа. Публичная выдача объявлений и каталог справочников остаются доступными без входа.

## 9. Разработка и поддержка

Публичный репозиторий содержит только веб-клиент. API, сборщики, схема SQLite, тесты и systemd-файлы находятся в закрытом репозитории [georealt/backend](https://github.com/georealt/backend). Не сохраняйте в публичном репозитории токены, `.env`, приватные ключи, базы данных, телефонные списки и данные пользователей.

Прежде чем менять сборщик нового источника:

1. Зафиксировать публичную выдачу и структуру подробного объявления.
2. Добавить адаптер к общей модели, ограничение запросов и тесты на сохранённых/искусственных ответах.
3. Настроить базовый снимок, чтобы старый каталог не отправился как новые объявления.
4. Добавить источник в API, фильтры интерфейса и документацию.
5. Проверить правила площадки и права на использование её контента.

Подробные серверные команды, конфигурация и модель данных описаны в README закрытого backend-репозитория.
